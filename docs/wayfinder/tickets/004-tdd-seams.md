# Agree the TDD seams

Status: resolved
Kind: `wayfinder:grilling`
Blocked by: [Design the search pipeline call stack](003-search-pipeline-call-stack.md)

## Question

At which seams will the test-first implementation test global find, confirmed
with the human before any test is written (per the `tdd` skill)? Name each
seam's public interface, what behavior it observes, and what stays below it
(decoders, jobs internals, fuzzy internals). No tests are written here —
this ticket resolves the agreement the red-green loop will build on,
one vertical slice at a time.

## Resolution

Agreed in one grilling round (all recommendations accepted unchanged).

### Seams (public interfaces under test)

1. **Outer lib seam — `grep::run(...)`.** The `grep` module goes public on
   the `nw-tools` lib (binary modules stay private); tests drive queries in
   and assert rows/report/JSON out, `writer_fixture.rs` precedent. Observes
   end-to-end behavior: name hit, content hit, exact mode, scoping flags,
   JSON shape, skip-count summary, cancelled-partial drain. Below it:
   everything, incl. clap parsing (one smoke test, not a suite).
2. **Adapter port seam — `&dyn SearchAdapter`.** Each adapter tested through
   the port production callers use, on hand-written minimal literals (never
   fixtures generated by the code under test). Observes predicate + decode +
   extract + cap + skip translation. Below it: decoder crates, fuzzy internals.
3. **Merger seam — pure function.** Hand-built hit vectors in, tier-ordered
   rows + overflow counts + skip summary out. No threads, paks, or files.
   Observes ordering, per-entry caps, `~` marking, count arithmetic.
4. **Cancellation seam — injected token.** Pre-cancelled `CancellationToken`
   proves partial drain. Below it: signal handling, pool mechanics.

### Explicitly below every seam

Numeric fuzzy scores (assert order and membership only — scores are
ranking-internal, asserting them is tautological coupling); jobs pool
mechanics; decoder-crate internals (their own suites); ratatui pixels, ever.

### Loop rules for implementation

Red-green vertical tracer slices through seams 1→3; no horizontal slicing
(no adapter test-suite written before its adapter exists); refactoring stays
out of the loop per the `tdd` skill.
